# 💙 ENHYPEN BIAS FOR ENGENES

Welcome to **ENHYPEN BIAS FOR ENGENES**, an interactive fan website created for ENGENEs around the world. This project allows fans to choose their ENHYPEN bias, learn more about them, and celebrate their journey as an ENGENE.

---

## 🌟 Features

- 💙 Welcome page for ENGENEs
- 👤 Choose your favorite ENHYPEN member (bias)
- 📖 Dynamic member introduction
- 🖼️ Member images
- 🎂 Member information
  - Name
  - Age
  - Birthday
  - Nationality
  - Position
  - Qualities
- 📅 Select the year you became an ENGENE
- 🌸 Beautiful flower animation
- 🎉 Appreciation message for every ENGENE
- 🔄 Continue or Leave option
- 📱 Responsive design for desktop and mobile
- 🎵 Background music (optional)
